How It Works

Follow these steps to run the Missing Matches Check.

1

Prepare Your Input Files

You need 4 files:
• TAC Mapped CSVs — exported from Trading Admin Client (mapped fixtures for TV1/TV2)
• TAC Unmapped CSVs — exported from Trading Admin Client (unmapped fixtures for TV1/TV2)
• BET PT XML Excel — the main match file with Game ID, Team 1, Team 2, Black Listed, etc.
• Blacklist Reference Excel — sport/competition blacklist entries with comments

2

Go to "Run Check"

Click Run Check in the navigation bar. You'll see a form with file upload fields for each input.

3

Upload Your Files

Click each file input and select the corresponding file. For TAC CSVs, you can select multiple files at once (hold Ctrl/Cmd and click).

4

Click "Run Pipeline"

The system loads all files in your browser, normalizes the data, builds lookup dictionaries, applies the 5 business rules in priority order, and generates the output. No data leaves your computer.

5

Review Results & Download

After processing, you'll see a summary with counts for each category. Click Download Output Excel to save the result file.

6

Open the Output File

Open the downloaded Excel file. The Comment column (last column) shows: "Already Mapped", "Needs to be Mapped", "Blacklisted", a reference comment, or empty.

How It Works

Step-by-step guide to validate your match mappings.

1

Prepare Files

You need:
• TAC Worked Matches — copy rows from Excel (with headers: Date, Sport Name, Event Name, CutOff Date, Portugal Fixture Id) and paste directly
• Betradar File — Excel/CSV with columns: EventId, Date, Time, Sport, Event, Hometeam, Awayteam
• BET PT Sheet (optional) — fallback for events not found in Betradar. Columns: Game ID, Date/Time, Sport Name, Country, Team 1, Team 2

2

Paste & Upload

Go to "Validate". Paste your TAC data directly from Excel into the text area, then upload the Betradar file (and optionally BET PT Sheet).

3

Click "Run Validation"

The system matches records by Portugal Fixture Id = EventId, then compares teams (fuzzy), dates/times (±15 min tolerance), and sport names. If an event isn't found in Betradar but a BET PT Sheet is provided, it falls back to matching there.

4

Review Results

Each row gets a status: Correct Review Wrong No Mapping

5

Download

Click "Download Excel" to save the results for further review.

Validation Rules

How each field is compared:

FieldMethodDetails
Fixture IdExact matchTAC "Portugal Fixture Id" = Betradar "EventId". Falls back to BET PT "Game ID" if not found.
TeamsFuzzy matchNames normalized (lowercase, no country codes, no special chars). Handles reversed order. Score 0-100.
Date/TimeToleranceSame day + up to 8 hours for most sports. Tennis allows ±3 days.
SportNormalizedLowercase comparison of sport names.

Status Logic

StatusCondition
CorrectTeam score ≥ 85, time diff ≤ 15 min, sport matches
ReviewTeam score ≥ 60 but < 85, or time diff > 15 min but ≤ 60 min
WrongTeam score < 60, or time diff > 60 min, or sport mismatch
No MappingNo matching EventId found in Source file
